The brightness control in the taskbar uses Android's "Modify system settings" permission. It is used only to adjust screen brightness and is requested the first time you press the brightness button. No other system setting is changed.

In Classic mode, swiping down on the home screen opens the notification panel using Android's "expand status bar" permission. This permission only opens the panel; it does not read notifications.

Приложение не собирает ваше имя, адрес электронной почты, местоположение, контакты, сообщения или любые другие персональные данные. Оно не использует рекламные, аналитические или отслеживающие библиотеки.

Эти данные хранятся в защищённой области памяти, которую Android выделяет каждому приложению и к которой другие приложения не имеют доступа.

В классическом режиме, пока включены «Рекомендуемые приложения», считается, сколько раз вы открываете каждое приложение из лаунчера, чтобы самые используемые отображались вверху списка приложений. Чтобы показывать их на рабочем столе и в меню приложений, названия и значки установленных приложений считываются через стандартный интерфейс лаунчера Android (LauncherApps). Этот список обрабатывается только на устройстве, не сохраняется и никому не передаётся.

Для правильного отображения панели задач и темы на устройстве также считываются уровень заряда батареи, цвета обоев и ассистент по умолчанию; эти данные не сохраняются и не передаются.

  • Подсчитывается только количество уведомлений от каждого приложения.
  • Заголовок, текст и содержимое уведомлений не читаются и не сохраняются.
  • Никакие данные не покидают устройство.

Если не дать разрешение, приложение работает как обычно, просто точки не отображаются. Его можно отключить в любой момент в настройках Android.

5. Разрешение на изменение системных настроек (режим рабочего стола)

Регулятор яркости на панели задач использует разрешение Android «Изменение системных настроек». Оно нужно только для регулировки яркости экрана и запрашивается при первом нажатии на кнопку яркости. Другие системные настройки не меняются.

В классическом режиме свайп вниз на рабочем столе открывает панель уведомлений с помощью разрешения Android «разворачивание строки состояния». Это разрешение только открывает панель и не читает уведомления.
